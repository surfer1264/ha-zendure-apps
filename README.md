# Zendure Apps für Home Assistant

App-Repository für Home Assistant mit zwei Apps:

| App | Beschreibung |
| --- | --- |
| [Zendure Dashboard Proxy](zendure_proxy) | Lokaler Proxy für das Zendure-Dashboard (löst das CORS-Problem der Shelly-Firmware) |
| [Zendure Multi-Configurator](zendure_installer) | Configurator und Upload-Helfer für die Zendure-Shelly-Scripte (Controller, zenDash-API + Watchdog) |

## Installation

[![Repository zu Home Assistant hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fsurfer1264%2Fha-zendure-apps)

Oder von Hand: *Einstellungen → Apps → App-Store → ⋮ → Repositories* und
`https://github.com/surfer1264/ha-zendure-apps` eintragen. Danach erscheinen
beide Apps im App-Store.
